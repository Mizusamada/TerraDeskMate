# GPT-SoVITS、参考推理和角色权重

## 轻量版要自行准备
安装完整GPT-SoVITS Windows环境，含可用Python、PyTorch及官方依赖和相应v2预训练模型。单独安装Python或只下载一个pth都不足以启动；推荐使用其完整发行环境。所有角色共用一份环境，不按角色重复安装。

在声音输出选择本地GPT-SoVITS，填环境根、Python、API地址和基础GPT/SoVITS路径，或点帮忙识别。确认应用建议，再保存。API使用localhost，例如http://127.0.0.1:9880。点启动本地服务，等待就绪，再试听；程序只管理自己启动的进程，不停止其他Python服务。

全量源码目录提供speech-runtime/GPT-SoVITS及default-template.json；构建后应用解析相对路径。其他电脑仍需匹配Windows与可用运行库；可用CUDA时自动选择，否则CPU。未在外部电脑实测，不能保证每台机器均无需额外处理。

## 参考推理
开启自动角色参考，切角色会换成本角色主参考、辅助录音和原文。语种不同可以跨语言合成；参考录音语言与输出语种独立，译文不能当逐字原文。主参考通常要求3–10秒；缺可靠原文可按后端能力使用无文本模式，不能伪造转写。

## 权重包
导入语音权重包后路径与样本自动登记。状态trained_unverified表示产物存在但音色尚未独立验证；完成独立试听/确认之后才可启用已验证训练音色模式。程序不会仅因导入两个文件就改成verified。未提供权重的角色可以用参考推理，但不能说它已有训练成果。

GPT ckpt与SoVITS pth需匹配版本，不能把SoVITS当RVC/Seed-VC模型。不同角色不得共用角色专属权重；通用基础权重和Python环境可以共享。

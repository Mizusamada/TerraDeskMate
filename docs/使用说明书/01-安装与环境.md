# 安装与环境

## 最简单：双击安装程序
在仓库安装程序/2026-10-09-r1目录双击Setup.exe。全量版所有同名.bin必须与EXE一起下载；轻量版为单EXE。安装后从开始菜单或选中的桌面快捷方式启动，不需Node.js或npm。未做发布者代码签名，Windows可能提示未知发布者；请使用完整可信下载文件。

下面是开发者从源码构建的步骤，不是普通安装用户必做。

## 这是源码目录，不是单个EXE
这两个目录保留可构建源码和资源。首次运行须安装Windows x64版本Node.js（建议22.12或更高）及npm。在目录打开终端：

```powershell
npm ci
npm run build
npm start
```

npm ci会安装package-lock.json固定的依赖，包括Electron、esbuild、TypeScript、tsx和ws。首次需网络；网络不可用时先准备依赖，不要删lockfile后随意升级。后续已构建时使用启动泰拉桌伴.cmd或npm start。

## 普通用户便携版
由源码执行npm run package:portable，可在release下生成新的Windows目录。复制整个目录，运行TerraDeskMate.exe或启动脚本；不能只拷贝EXE。便携版已经含Electron，不要求用户另装Node.js。源码中的角色基础包/语音权重包目录不自动塞入轻量本体。

## 依赖表
| 功能 | 需准备 | 不需要 |
|---|---|---|
| 显示、动作、原声、字幕、拖拽、提醒 | 完整应用目录及角色基础资源；Windows x64 | API密钥、Python、GPT-SoVITS |
| AI文字对话 | 可用的兼容LLM服务、模型ID；该服务要求的密钥 | 本地TTS |
| AI语音合成 | GPT-SoVITS完整环境/基础权重，或已配置的云端语音服务 | 每个角色重复安装Python |
| 角色音色训练 | 独立Python/GPT-SoVITS训练依赖、基础权重、核对后的自有样本；足够内存/显存 | 云GPU租赁不是自动步骤 |
| 腾讯实时ASR | 腾讯AppID、SecretID、SecretKey及开通的实时识别服务、麦克风权限 | LLM Key不能替代这些凭据 |
| Seed-VC音频到音频 | 单独Seed-VC环境、对应通用模型/config、输入音频与目标参考 | GPT-SoVITS权重不能改名当VC权重 |
| 源码克隆与发行资源 | Git、Release资源下载 | 不使用收费Git LFS |

## 两版差异
全量版assets/builtin包含全部已提供角色、皮肤、原声、参考资料及已有训练权重，speech-runtime是全角色共用的一份离线环境。轻量本体只带Amiya和通用敌人资源，不含Python/GPT-SoVITS；其余角色/权重在外部分类目录，用户选需安装。

## 首次显示
启动只打开控制中心，不自动生成桌宠。部署页选择角色、皮肤和动作组，保存后点显示桌宠。安装环境或填配置不代表服务已运行，更不代表音色已经训练/验证完成。

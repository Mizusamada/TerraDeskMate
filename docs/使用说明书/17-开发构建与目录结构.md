# 开发、构建和公开目录结构

- apps/desktop/src：Electron主进程、preload、控制中心与透明桌宠/敌人渲染器。
- services/core/src：配置、人设、语音、模型、资源包、物理/窗口、训练与持久化业务。
- packages/contracts/src：跨模块数据契约与默认配置。
- scripts：启动、构建静态资源、生成便携目录、固定本地训练脚本。
- assets/builtin：本体资源。全量全部角色；轻量只有Amiya及通用敌人。
- 角色基础包：轻量外部按角色分类的完整导入文件夹。
- 语音权重包：轻量外部按角色分类的真实权重；目录.json列明未提供者。
- speech-runtime：仅全量版的一份共用运行环境。
- docs/使用说明书：功能手册；没有个人测试资料/聊天/缓存/历史包。

开发先npm ci，再npm run build；npm run typecheck只作类型检查，源码整理版不提供测试资料/测试脚本。npm run package:portable只构建与打包，不自动运行测试，也不覆盖已有交付目录。

大文件通过.gitattributes使用Git LFS。仓库源码与用户下载的便携发行包分开：不要把node_modules、dist、release、用户数据、密钥或私人存档提交。上传GitHub由维护者自行操作，本工具不会上传。

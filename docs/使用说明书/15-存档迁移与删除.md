# 存档、迁移、更新与删除

存档页可创建本机存档，导出个人.terrasave文件或选择存档读入。包含角色/实例设置、聊天、记忆、导入资源和已保存声音，不包含API密钥。读入前自动备份，电脑权限关闭，新电脑重新配置凭据。

应用资源目录与个人存档是两件事：全量版复制整应用；轻量版复制本体，并重新导入所需基础/权重包或恢复个人存档。不要只复制exe；源码使用者还需npm依赖和构建。

关闭程序再更新应用文件；不删除Windows用户数据即可保留个人设置。彻底清理前先导出存档，确认目标确实是应用的数据目录。旧运行进程不会自动加载改过的源码，要正常退出后重新打开。



## 两个版本不要同时运行
全量与轻量是同一产品的不同资源发行，默认共享当前Windows用户数据。建议选一版常用，退出已有程序后再切另一版；卸载不清空用户设置。角色包导入到用户目录，不要求原GitHub下载目录一直留在原位置。

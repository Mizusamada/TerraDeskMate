# Terra DeskMate 0.3.2: 国家图书馆联动时装模型

新增三套可播放 Spine 3.8.99 桌宠模型：黍「源远流长」、烛煌「夜行烛火」、琳琅诗怀雅「盛世之象」，每套包含基建、正面、背面动作组。角色总数仍为 434，Full/Plus/Standard 模型总数从 2853 增至 2862；旧皮肤和角色数据不删除。

## 使用方式

- Full、Plus、Standard：下载**与已安装版本同名**的 `TerraDeskMate-<edition>-NLC-0.3.2.zip`，解压完整目录，关闭桌宠后执行 `powershell -NoProfile -ExecutionPolicy Bypass -File "应用更新.ps1" -Target "现有安装目录"`。更新器先验证清单哈希，再备份并替换 32 个官方资源文件；不改私人设置、密钥、聊天、记忆或语音权重。
- Light：下载 `TerraDeskMate-light-NLC-0.3.2.zip`，解压后从软件“下载管理”逐个选择 `role-packs` 中**含 manifest.json 的角色子目录**导入。旧角色包须重新导入对应角色，三个包均包括该角色原皮、既有皮肤和本次新皮肤；不要仅复制新模型文件。
- **这是 0.3.1 及兼容旧安装的增量资源更新，不是首次安装器。**首次安装请先按原仓库 0.3.1 说明取得相应完整安装包，再执行本更新。原 0.3.1 EXE 不会自动包含 0.3.2 三款皮肤。

## 验证与边界

资源清单 27 文件逐项 SHA256；208/208 核心测试、类型检查和构建通过。三角色共 27 个新旧模型的真实 WebGL 动画采样没有裁切或空帧；三款新皮肤各抽看待机和战斗图。隔离 Light 包安装和三个资源补丁应用/哈希/私人文件保全通过。真实 Electron 闭环验证三款皮肤逐个显示、动作、隐藏及重启后不自动出场，页面错误为零。初次专项试跑曾在 CDP 建连阶段超时；后续改用已验证的 Playwright 通道并纠正窗口选择后通过。其他物理电脑、云服务、所有动作人工逐帧效果未验收。
